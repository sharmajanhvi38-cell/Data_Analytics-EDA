# Student Performance Data Analysis – EDA

## Project Overview
This project performs Exploratory Data Analysis (EDA) on student performance data.

## Dataset
The dataset contains information about:
- Study Hours
- Attendance
- Marks

## Analysis Performed
- Dataset overview and basic information
- Data cleaning and validation
- Study Hours vs Marks analysis
- Attendance vs Marks analysis
- Correlation analysis
- Data visualization

## Key Findings
- Students with higher study hours generally achieve higher marks.
- Higher attendance is associated with better academic performance.
- Study hours and attendance show a strong relationship with marks.
- The dataset contains no missing values.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

## Files
- `Data_Analytics_Task_EDA.ipynb` – Complete analysis notebook
- `student_performance_dataset.csv` – Dataset

## Conclusion
The analysis shows that study hours and attendance are strongly related to student academic performance.
